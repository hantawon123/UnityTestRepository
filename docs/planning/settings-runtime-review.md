- 기준: `origin/develop`의 `9b2cbe06`
- 상태: 구현 및 아래 자동 검증 완료. 사용자 검토 전이며 MR 생성·push·배포 미실행.

## 변경 내용

홈과 로비에서 기존 6개 탭의 설정 화면 및 저장 시스템을 공유한다. 로비 메뉴의 환경설정 버튼으로 화면을 열고 닫아도 방 연결과 Lobby 상태를 유지한다. 미적용 변경은 확인 절차를 거쳐 버리고, 캐시된 화면을 다시 열 때 저장값으로 새 초안을 만든다. 설정 화면 동안 채팅과 카메라 입력을 차단하고, 다른 참가자가 게임을 시작하면 설정 화면을 닫는다.

1인칭 마우스 감도 및 X/Y 반전, 3인칭 마우스·카메라 감도 및 X/Y 반전을 실제 카메라에 연결한다. 설정은 적용된 공유 값을 읽으며, 씬 로드 및 로비 카메라 생성 시 연결한다. 기본 감도 50은 기존 회전 속도를 유지한다. 각 슬라이더의 배율은 0~100을 0~2배로 매핑한다. 3인칭은 마우스 배율과 카메라 배율을 곱하므로 두 값 모두 100이면 4배이다. V 시점 전환은 커서를 캡처한 상태에서만 허용한다.

사용자 확인에 따라 피드백 보내기는 기존 미연결 안내를 유지하며 API 전송은 후속 작업이다. 언어는 기존 한국어 목록을 유지한다. 그래픽·오디오·인터페이스의 미연결 세부 옵션(741/742/744), 일반 행동 키 재지정은 이번 범위에 포함하지 않는다.

## 검증

- Unity 6000.3.22f1, WebGL 대상의 Editor 컴파일 및 EditMode 관련 테스트: **94/94 통과**.
- PlayMode 실제 SettingsView 재열기·저장값 표시·로비 상태 유지, 실제 PlayerCameraRig 설정 바인딩·모달 중 V 입력 차단: **2/2 통과**.
- `git diff --check` 통과.
- 실제 Photon 다중 참가자 및 브라우저 플레이 검증은 미실행. 전체 WebGL 빌드 및 배포도 미실행.
- 확장 EditMode 실행은 102개 중 100개 통과, 기존 `PlaySettingsPresenterTests` 2개 실패. 테스트가 `food`/`fruit` 카테고리 보존을 기대하지만 현재 `PlaySettingsCategoryCatalog`는 랜덤만 제공하고 뷰가 미지원 값을 정규화한다. 해당 테스트·뷰·카탈로그·규칙 모델은 기준 develop과 동일하며 이번 변경에 포함하지 않았다. 별도 기준 브랜치 실행으로 재현한 결과는 아니다.

결과 파일은 작업 공간 상위 `.build/settings-runtime-verified.xml`, `.build/settings-runtime-playmode.xml`, 확장 실행 `.build/settings-runtime-tests.xml`에 보관한다.

## 사용자 확인 순서

1. 홈 설정에서 감도를 변경하고 적용 후 재진입: 저장값 유지. 미적용 변경 후 뒤로가기에서 취소/적용 경로 확인.
2. 로비 Esc → 환경설정 → 적용/뒤로가기: 방 연결과 참가자 목록 유지, 메뉴로 복귀. 설정 중 이동·시점 전환·채팅 입력 차단 확인.
3. 1인칭/3인칭을 V로 전환하여 감도·축 반전 확인. 50 기본값에서 기존 조작감 유지 확인.
4. 재접속 및 다음 게임에서도 저장값 유지 확인. 게스트 설정 화면이 열린 동안 호스트 게임 시작 시 화면 종료와 게임 전환 확인.
